Our Commitment to Safety

At SplitGDPS, user trust is our highest priority. We want to be 100% clear: SplitGDPS does not, and will never, contain malware, spyware, or any malicious code. Our project is built for players, by players. We have no interest in compromising the security of our users.

Understanding False Positives

You may occasionally see a warning from Windows Defender or other antivirus software when downloading or running SplitGDPS. These are what we call "False Positives."

A false positive occurs when an antivirus program incorrectly identifies a safe file as a threat. This is common with independent projects and custom game servers because:

  • Unrecognized Publishers: Since we are independent developers and not a multi-billion dollar corporation, our software doesn't always have an "expensive" digital signature that antivirus companies automatically trust.
  • Heuristic Analysis: Antivirus programs use "best guesses" to identify patterns. Sometimes, standard game networking code can look similar to patterns they are trained to watch out for.
  • InstallForge: Some antivirus programs (notabally BitDefender), flag InstallForge installers as malware. This is our installer engine and is not malware.

Why We Are Different

Many applications that trigger antivirus warnings do so because they use "shady" tactics to hide their code. We do not do this.

1. No Code Obfuscation: We do not scramble or "obfuscate" our code to hide what it's doing. Our code remains readable to ensure transparency and to allow security researchers to verify that it is safe.

2. No Memory Modification: Unlike some mods or cheats that inject code into other running processes (memory hijacking), SplitGDPS operates within its own boundaries. We do not touch your system memory or other applications.

How to Proceed

If your antivirus flags the file, you can typically "Allow" or "Add an Exception" for SplitGDPS. We encourage you to scan our files using services like VirusTotal, where you will see that the majority of reputable engines recognize the file as clean.
